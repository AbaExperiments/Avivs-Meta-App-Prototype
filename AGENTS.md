# AGENTS.md

This is a test lab for Muse Spark. You can create/edit files, run builds/tests, use git.

## Lab Rules

- Feel free to create new files in `src/` and `src/examples/`
- Run `npm run build` to type-check and `npm run test` to verify
- Use `npm run dev` for quick iteration
- Use `npm run lint` to check code style
- Git is available - commit as you experiment

## Structure

- `src/index.ts` - entry point
- `src/examples/hello.ts` - placeholder hello example
- `src/examples/game.ts` - placeholder game example
- `src/**/*.test.ts` - vitest tests
